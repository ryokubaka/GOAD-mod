# w11-23h2

- Extension name: `w11-23h2`
- Description: Hardened Windows 11 23H2 workstation for GOAD / GOAD-Light / GOAD-Mini
- Ludus template: `win11-23h2-x64-enterprise-template`
- Machine: `{{lab_name}}-W11-23H2` (`casterlyrock.sevenkingdoms.local`, `{{ip_range}}.31`, vlan 10)
- Providers: virtualbox / azure / vmware / aws / ludus / proxmox

## Lab info

- hostname: casterlyrock
- Administrators: tywin.lannister, jaime.lannister
- RDP Users: Lannister group
- Security: run_as_ppl, powershell restricted, ASR (LSASS / PSExec+WMI)

## Prerequisites

Build the Ludus template from [ludus-source-bsl](https://github.com/badsectorlabs/ludus-source-bsl/tree/main/templates):

```
ludus templates build -n win11-23h2-x64-enterprise-template
```

## Installation

```
load <instance_id>
install_extension w11-23h2
```

## Workstation IP map (vlan 10)

| Extension   | IP octet |
|-------------|----------|
| w11-23h2   | .31      |
| lx01        | .32      |
| w11-24h2   | .34      |
| w11-25h2    | .35      |

All four can be installed together in one range.
