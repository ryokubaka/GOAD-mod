# w11-25h2

- Extension name: `w11-25h2`
- Description: Hardened Windows 11 25H2 workstation for GOAD / GOAD-Light / GOAD-Mini
- Ludus template: `win11-25h2-x64-enterprise-template`
- Machine: `{{lab_name}}-W11-25H2` (`highgarden.sevenkingdoms.local`, `{{ip_range}}.35`, vlan 10)
- Providers: virtualbox / azure / vmware / aws / ludus / proxmox

## Lab info

- hostname: highgarden
- Administrators: renly.baratheon, stannis.baratheon
- RDP Users: Baratheon group
- Security: run_as_ppl, powershell restricted, ASR (LSASS / PSExec+WMI)

## Prerequisites

Build the Ludus template from [ludus-source-bsl](https://github.com/badsectorlabs/ludus-source-bsl/tree/main/templates):

```
ludus templates build -n win11-25h2-x64-enterprise-template
```

## Installation

```
load <instance_id>
install_extension w11-25h2
```

## Workstation IP map (vlan 10)

| Extension   | IP octet |
|-------------|----------|
| w11-23h2   | .31      |
| lx01        | .32      |
| w11-24h2   | .34      |
| w11-25h2    | .35      |

All four can be installed together in one range.
