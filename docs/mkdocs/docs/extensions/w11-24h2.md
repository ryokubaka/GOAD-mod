# w11-24h2

- Extension name: `w11-24h2`
- Description: Hardened Windows 11 24H2 workstation (virtual TPM) for GOAD / GOAD-Light / GOAD-Mini
- Ludus template: `win11-24h2-x64-enterprise-tpm-template`
- Machine: `{{lab_name}}-W11-24H2` (`catrock.sevenkingdoms.local`, `{{ip_range}}.34`, vlan 10)
- Providers: virtualbox / azure / vmware / aws / ludus / proxmox

## Lab info

- hostname: catrock
- Administrators: tywin.lannister, jaime.lannister
- RDP Users: Lannister group
- Security: run_as_ppl, powershell restricted, ASR (LSASS / PSExec+WMI)

## Prerequisites

Build the Ludus template from [ludus-source-bsl](https://github.com/badsectorlabs/ludus-source-bsl/tree/main/templates):

```
ludus templates build -n win11-24h2-x64-enterprise-tpm-template
```

## Installation

```
load <instance_id>
install_extension w11-24h2
```
